# 🚀 How to Run HH-BikeWatch

## Quick Start

The project is in the `hh-bikewatch` subdirectory. Run these commands:

```bash
cd hh-bikewatch
npm run dev
```

Then open http://localhost:5173 in your browser.

## Full Instructions

1. **Navigate to project directory:**
   ```bash
   cd /Users/tobiaskujac/Documents/Cursor_hackathon/Cursor_Hackathon/hh-bikewatch
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Open browser:**
   - Navigate to http://localhost:5173
   - The app will load with demo data automatically

## If you see errors:

If you see "package.json not found", you're in the wrong directory. Make sure to:
```bash
cd hh-bikewatch
```
