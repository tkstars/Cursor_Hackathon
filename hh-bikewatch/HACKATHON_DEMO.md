# HH-BikeWatch - Hackathon Demo Guide 🚴

## 🚀 Quick Demo Script (60 seconds)

### 1. **Opening (10 sec)**
"More than half of Hamburg cyclists feel unsafe. HH-BikeWatch is a community-driven map where cyclists report and avoid dangers."

### 2. **Show the Map (15 sec)**
- Point out the 6 demo hazards
- Click on markers to show details
- Highlight color coding: Red = High danger, Orange = Medium, Yellow/Blue = Low

### 3. **Report New Hazard (20 sec)**
1. Click "Report Hazard" button
2. Select "Blocked Lane" from dropdown
3. Click on map (e.g., near Alster)
4. Show new marker appears instantly
5. Refresh page - data persists!

### 4. **Mobile Demo (10 sec)**
- Resize browser to mobile size
- Show responsive design
- "Cyclists can report hazards on-the-go"

### 5. **Closing (5 sec)**
"Built in 60 minutes with React, Leaflet, and Tailwind. Making Hamburg cycling safer, one report at a time!"

## 🎯 Key Points to Emphasize
- **Real problem**: 50%+ cyclists feel unsafe
- **Visual solution**: See dangers before you ride
- **Community-driven**: Everyone can contribute
- **Works immediately**: No signup, no backend needed
- **Mobile-first**: Report while cycling

## 💡 If Asked About Technical Details
- **Why Local Storage?**: Fast MVP, works offline, no server costs
- **Future vision**: City API integration, route planning, hazard verification
- **Scalability**: Could add backend, user accounts, voting system

## 🛠️ Troubleshooting
- **Map not loading?**: Check internet connection (needs OpenStreetMap tiles)
- **Markers not saving?**: Check browser allows localStorage
- **Need fresh start?**: Click "Reset Demo" button

## 📱 Best Demo Device
- Modern browser (Chrome/Firefox/Safari)
- Desktop for main demo
- Show mobile responsiveness by resizing window

## 🎬 Video Recording Tips
1. Start with full-screen browser
2. Have map pre-loaded with demo data
3. Practice the hazard reporting flow
4. Keep mouse movements smooth
5. End with mobile view resize

---

**Remember**: Focus on the problem solved, not the code!
